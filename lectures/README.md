# Курс: «Как написать Telegram-бота на aiogram 3» (на примере @blackmagicwoman)

Это разбор реального проекта — бота рок-сообщества — как учебного материала. Мы
не пишем абстрактный «hello world», а вскрываем работающий бот и смотрим, **как и
почему** в нём сделана каждая подсистема: гейт подписки, меню, тесты, квест,
база данных, FSM.

Курс рассчитан на того, кто **уверенно знает Python** (включая `async/await`), но
не работал с aiogram. Поэтому базовый синтаксис языка мы не объясняем — фокус на
архитектуре, паттернах aiogram 3 и инженерных решениях.

## Как пользоваться

Лекции идут по нарастанию: от «что вообще такое апдейт» к движку квеста и
эксплуатации. Можно читать подряд, можно прыгать к нужной теме — в начале каждой
лекции написано, что нужно знать заранее.

Диаграммы оформлены в [Mermaid](https://mermaid.js.org/). Они корректно
рендерятся на GitHub, в VS Code (расширение *Markdown Preview Mermaid Support*),
Obsidian, Typora и большинстве современных просмотрщиков Markdown. Если ваш
просмотрщик не умеет Mermaid — код диаграммы всё равно читается как текст.

## Стек проекта

- **Python 3.11+** — `async/await`, `match`-нестрого, современные аннотации (`set[int]`, `str | None`).
- **[aiogram 3.28](https://docs.aiogram.dev/)** — асинхронный фреймворк для Bot API: роутеры, фильтры, встроенный FSM, middleware.
- **aiosqlite + SQLite** — локальная БД без внешних сервисов.
- **python-dotenv** — секреты и настройки в `.env`.
- Режим работы: **long polling** (про webhook — в лекции 10).

## Главный принцип проекта

> Вся **логика** — в коде (`*.py`), весь **контент** — в `content/*.json` и `.env`.

Чтобы добавить факт, поменять плейлист или переписать вопрос теста, программист не
нужен: правится JSON, бот перечитывает файлы на каждый запрос. Этот принцип
красной нитью проходит через весь курс — обращайте на него внимание.

## Карта проекта (одним взглядом)

```
main.py                      # запуск: логирование, Bot, Dispatcher, polling
config.py                    # чтение .env + загрузка контента из JSON
handlers/
  start.py                   # /start и проверка подписки (гейт)
  menu.py                    # главное меню, плейлист, чат, UI-помощники (safe_edit)
  facts.py                   # рандомные факты без повторов
  tests.py                   # выбор теста + движки зодиака, стиля (FSM) и квеста (FSM)
  events.py                  # мероприятия
  admin.py                   # /stats
  fallback.py                # перехват устаревших кнопок (последним)
keyboards/kb.py              # все inline-клавиатуры и схема callback_data
middlewares/subscription.py  # проверка подписки на каждое действие
database/db.py               # инициализация и запросы к SQLite
states/states.py             # FSM-состояния (тест на стиль, квест)
content/                     # весь контент в JSON (правится без программиста)
```
