# Фото групп для «Турнир групп»

Сюда — по одному промо-фото на каждую группу из `content/tournament_bands.json`,
имя файла должно совпадать с полем `photo` в этом JSON (например,
`metallica.jpg` для группы с `"photo": "metallica.jpg"`).

Пропорции подгонять не нужно — на клиенте фото обрезается по кругу
(`object-fit: cover`), браузер сам кадрирует по центру.

Пока фото группы нет (или файл не найден) — вместо него показывается
нейтральная иконка-заглушка, это не баг.
